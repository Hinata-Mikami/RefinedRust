[手動検証中]　sweep の仕様
	事前条件marks_colsed： 
mark : true かつ next が存在するなら next も mark : true
	※A[true] → B[false] だと，Bを解放するとA.next がdangling pointerになるから
	※mark 関数の事後条件としても付与
	事後条件：
	keep_marked xs marks … 「xs について，markが trueのもののみ残す」として，
	更新された Heap refinement は下記のようになる
#[rr::observe("h.ghost" : 
" let '(vals, locs, nexts, marks) := h.cur in 
  let vals' := keep_marked vals marks in 
  let locs' := keep_marked locs marks in 
  let nexts' := keep_marked nexts marks in 
   (vals', locs', nexts', replicate (length locs') false) ")]
