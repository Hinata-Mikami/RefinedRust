今のコードでは `#[rr::trust_me]` が付いているのは `set_next` だけです。

```rust

#[rr::returns("()")]
unsafe fn set_next(...) { ... }
```

一方、`read_next_value` はこうなっています。

```rust
#[rr::params("a" : "loc", "b" : "loc", "v1" : "Z", "v2" : "Z", "γ")]

#[rr::returns("v2")]
unsafe fn read_next_value(&mut self, cell: *mut Cell) -> i32 {
    let next = (*cell).next;
```

## もう一点：`set_next` の spec は戻した方がよいです

今の `set_next` は、spec をコメントアウトして `#[rr::returns("()")]` だけになっています。

```rust
#[rr::trust_me]
// #[rr::params(...)]
// #[rr::args(...)]
// #[rr::requires(...)]
// #[rr::ensures(...)]
#[rr::returns("()")]
unsafe fn set_next(...) { ... }
```

これは危険です。`new` の中で `set_next(a, b)` を呼んでも、RefinedRust 的には「何も更新していない関数」に近くなります。

`trust_me` にする場合でも、**仕様は残す**べきです。

```rust
#[rr::trust_me]
#[rr::params("cell" : "loc", "next" : "loc", "v" : "Z", "old_next" : "loc")]
#[rr::args("cell", "next")]
#[rr::requires(#type "cell" : "(v, old_next)" @ "(Cell_inv_t <INST!>)")]
#[rr::ensures(#type "cell" : "(v, next)" @ "(Cell_inv_t <INST!>)")]
#[rr::returns("()")]
unsafe fn set_next(cell: *mut Cell, next: *mut Cell) {
    (*cell).next = next;
}
```

つまり、今の段階ではこうです。

```rust
#[rr::trust_me]
#[rr::params("cell" : "loc", "next" : "loc", "v" : "Z", "old_next" : "loc")]
#[rr::args("cell", "next")]
#[rr::requires(#type "cell" : "(v, old_next)" @ "(Cell_inv_t <INST!>)")]
#[rr::ensures(#type "cell" : "(v, next)" @ "(Cell_inv_t <INST!>)")]
#[rr::returns("()")]
unsafe fn set_next(cell: *mut Cell, next: *mut Cell) {
    (*cell).next = next;
}

#[rr::trust_me]
#[rr::params("a" : "loc", "b" : "loc", "v1" : "Z", "v2" : "Z", "γ")]
#[rr::args("(([v1; v2], (<$#> [a; b]), [b; a]), γ)", "a")]
#[rr::observe("γ": "([v1; v2], (<$#> [a; b]), [b; a])")]
#[rr::returns("v2")]

```
